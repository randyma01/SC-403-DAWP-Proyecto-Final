# Credenciales de Firebase Storage

Por motivos de seguridad, los archivos de credenciales privadas no se versionan en Git.

Para que la aplicación funcione en tu entorno local:
1. Solicita a tu compañero el archivo de credenciales:
   `techshop-4f012-firebase-adminsdk-fbsvc-84ad9b5cd0.json`
2. Coloca ese archivo directamente dentro de esta carpeta (`src/main/resources/firebase/`).
3. El archivo está protegido automáticamente por `.gitignore`, por lo que nunca se subirá al repositorio.
